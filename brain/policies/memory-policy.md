# MIA Memory Model

## Working Memory

Kurzfristiger Arbeitskontext einer laufenden Sitzung.

Pfad:

memory/working/

Dieser Speicher darf regelmäßig bereinigt werden.

## Episodic Memory

Speichert Ereignisse und abgeschlossene Sitzungen.

Pfad:

memory/episodic/

Beispiele:

- Sitzungszusammenfassungen
- durchgeführte Arbeiten
- wichtige Entscheidungen
- Fehlerereignisse

## Semantic Memory

Verifiziertes Langzeitwissen.

Pfad:

memory/semantic/

Nur bestätigte Informationen dürfen hier landen.

## Preferences

Stabile Einstellungen und Präferenzen.

Pfad:

memory/preferences/

Änderungen müssen nachvollziehbar bleiben.

## Kernregel

Eine Information gilt nicht als gelernt, nur weil sie geschrieben wurde.

MIA muss sie in einer neuen Sitzung wieder abrufen können.
