# MIA Master Skill Rules v1

A skill is not MASTER because it exists, was imported, or MIA can describe it.

MASTER requires all of:
1. Knowledge retrieval works without fabrication.
2. At least 8 scored attempts in the skill family.
3. Average score >= 0.90 and pass rate >= 0.90.
4. At least 3 unseen holdout/transfer cases passed.
5. At least one failure followed by correct diagnosis, remediation and successful retest.
6. Tool-capable skills require real tool evidence where safe and authorized.
7. High-stakes skills require current authoritative-source checks.
8. Coding skills require syntax/static checks plus relevant tests.
9. Server skills require observed state before change and verification after change.
10. No destructive or unauthorized security activity.
11. Old failures stay in history, but resolved weaknesses must be marked resolved instead of blocking forever.
12. Skills periodically retest to detect skill decay.

Statuses:
UNPROVEN = knowledge may exist, competence not tested.
ASSESSED = at least one scored test.
DEVELOPING = repeated tests with meaningful progress.
PROFICIENT = strong repeated performance but Master threshold not reached.
MASTER = all Master criteria passed.
